1、vm虚拟平台简介
	VMware Workstation(威睿工作站)，简称VM，是一款功能强大的桌面虚拟机软件.
	提供用户可在单一的桌面上同时运行不同的操作系统和进行开发、测试、部署新的应用程序的最佳解决方案
	
	目前常见的版本有17、16、15、14，最新的17版本是23年推出的，目前已经比较稳定
	
	VM简单来的来说就类似与一个操作系统的套娃工具，可以将win7、win10、win11、KALI、ubuntu等操作系统全部安装到VM工具中。
	这样能更高效的使用电脑
	
2、专业版和学习版
	17.6之前分为pro版本和player版本
	VMware Workstation Player‌：免费版，专为个人、学习和非商业用途设计，功能简洁，适合运行单个虚拟机。
	VMware Workstation Pro‌：付费专业版，面向企业、开发者和IT专业人员，支持多虚拟机、高级管理功能和商业使用。
	
	如果只是‌学习操作系统、运行一个 Linux 或旧版 Windows 虚拟机‌，‌Player 完全够用‌，且免费。
	如果需要‌同时运行多个虚拟机、做开发测试、管理企业虚拟环境、使用快照树或远程连接‌，则必须选择 ‌Pro 版本‌。
	
	最新的17.6是免费版本在百度网盘/网络安全/目录下
	也可以去官网下载:https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion
	自2024年11月11日起，VMware（现为Broadcom旗下产品）宣布对所有用户免费提供VMware Workstation-Fusion，包括个人、教育和商业用途。
	这一政策变更适用于VMware Workstation 17.6及更高版本，用户无需再购买许可证或输入密钥即可使用其全部功能。 ‌
	
	安装后通过ipconfig查看虚拟网卡地址
		以太网适配器 VMware Network Adapter VMnet1:
		以太网适配器 VMware Network Adapter VMnet8:
	如果以上这两个虚拟网卡已经创建，说明安装成功

3、创建虚拟机
	安装后，即可使用vm，第一步是要创建虚拟机
	选择典型（推荐）配置
	第二步要选择安装系统的映像ISO文件。比如win11可以到官网免费下载（https://www.microsoft.com/zh-cn/software-download）
	选择虚拟机保存的位置，注意放到大一点的磁盘傻瓜
	指定磁盘容量：选择将虚拟机保存为单个文件，这样效率会高一些
	            选择磁盘大小：比如设置为150G,不是一开始就占用150G。vm会根据实际情况使用磁盘空间，之后可以随时修改这个值
				
	硬件设置：
			网络:通常使用nat模式，即和宿主电脑使用同一个ip
				也可以选择桥接模式，并选择复制物理网络连接状态，这样虚拟机和宿主机相当于两个平行的电脑，使用不同的ip
