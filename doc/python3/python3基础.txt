19、字符串的驻留机制
	1）	Python仅保存一份相同且不可变字符串，不同的值被存放在字符串的驻留池中，Python的驻留机制对相同的字符串只保留一份拷贝
	后续创建相同字符串时，不会开辟空间，而是把该字符串的地址赋给新创建的变量
		例子：
			str6 = 'Hello'
			str7 = 'Hello'
			str8 = 'Hello'
			#id(object)函数返回对象的内存地址
			print(f"str6的地址是 {id(str6)}")#2231742076208
			print(f"str7的地址是 {id(str7)}")#2231742076208
			print(f"str8的地址是 {id(str8)}")#2231742076208
		"Hello"在内存中只有一份，放在驻留池中，str1,str2,str3都指向这个地址
		
	2）	驻留机制的几种情况,pycharm对驻留空间进行了优化，不适用以下几种情况
	    以下几种情况只使用于原生python
		2.1) 字符串是由26个英文字母大小写，0~9，_组成
		2.2) 字符串长度为0或1时
		2.3) 字符串在编译时期驻留，而非运行时
		2.4) -5~256的整数数字
	
	3)	当需要值相同的字符串时，可以直接从字符串池里拿来使用，避免频繁的创建和销毁，提升效率和节约内存。
	
20、python的数据类型转换
	案例：\python_projects\PythonExam\02_var_oper\09_数据类型转换.py
	1）隐式类型转换
		python变量的类型不是固定的，会根据变量当前值在运行时决定的，可以通过内置函数type(变量)来查看其类型，这种方式就是隐式转换/自动转换
		
		#python 变量的类型是根据变量使用的上下文在运行时决定的
		var1 = 10
		print(type(var1)) #int
		var1 = 1.1
		print(type(var1)) #float
		var1 = 'hello'
		print(type(var1)) #str		
		
		#在运算的时候，数据类型会向高精度转换
		var2 = 10
		var3 = 1.2
		var4 = var2 + var3
		print(f"var4={var4} var4的类型是：{type(var4)}")
		var2 = var2+1.1
		print(f"var2={var2} var2的类型是：{type(var2)}")
		
	2）显示类型转换
		如果要对变量数据类型进行转换，只需要将数据类型作为函数名即可，这种方式就是显示转换/强制转换
		一下几个内置的函数可以完成数据类型之间的转换。函数会返回一个新的对象/值，就是强制转换后的结果
		int(x),将x转换为一个整数
		float(x),将x转换到一个浮点数
		str(x),将x转换为一个字符串
		repr(x)，将对象转换为表达式字符串
		
		#显示类型转换
		var1 = 10
		j = float(var1)
		print(f"j={j},j的类型是：{type(j)}")
		var1 = "10.1"
		j = float(var1)
		print(f"j={j},j的类型是：{type(j)}")
		var1 = "10"
		j = int(var1) #python中值是浮点数的字符串不能强制转换成整型
		print(f"j={j},j的类型是：{type(j)}")
		va1 =10.1
		j = int(var1)
		print(f"j={j},j的类型是：{type(j)}")#float转换成int时，小数部分会被抹去
		var1 = 10
		j = str(var1)
		print(f"j={j},j的类型是：{type(j)}")

	3）显示类型转换的注意事项	
		int类型 float类型 都可以转换成str类型
		int转换成float时，会增加小数部分，float转换成int时，小数部分会被抹去
		str转int使用int(x) ,str转float使用float(x),浮点数的字符串不能强制转换成整型
		str转换成基本数据类型的时候，要确保str的值能正常转换，否则程序会报错：ValueError
		对一个变量进行强制转换，会返回一个数据/值，强制转换后，并不会影响原变量的数据类型

22、算数运算符
	案例：\python_projects\PythonExam\03_运算符\01_算数运算符.py
	
	算数运算符是对数值类型的变量进行运算的，在程序中使用的非常多
	+，-，*，/，加 减 乘 除
	%，取模（取余）
	//，取整除，返回商的整数部分（向下取整）,比如 9//2=4，注意：-9//2=-5，因为是向下取整
	**，返回x的y次幂，比如2**3 = 8 ，2的3次方
	
	#对于/ 除号，返回的值是浮点数
	print(10/3) #3.33333333...
	
	#对于// ，返回的值是整数，向下取整

32、原码、反码、补码
	假设使用一个字节来保存数字
	1) 整数二进制的最高位是符号位：0表示正数，1表示负数
		比如：3=>0000 0011 ,-3=>1000 0011
	2) 正数的原码，反码，补码都一样(三码合一)
	3) 负数的反码=它的原码符号位不变，其他位取反
		比如：-3 的原码是：1000 0011，那么其反码就是  1111 1100
	4) 负数的补码=它的反码+1	
		比如 -3的原码是 1000 0011 ，反码是：1111 1100 ， 补码是 1111 1101
	5）0的补码，反码都是0
	6）在计算机运算的时候，都是以补码的方式来运行的
	7）运算的结果也是补码，要看到实际的结果，需要在还原到原码

33、位运算符
	案例： \python_projects\PythonExam\04_进制\02_位运算.py
	位运算需要先把二进制数据转换成补码，运算结果也是补码，最后在转换为原码
	
	1）~ ，按位取反
	2）& ，按位与
	3）^ , 异或 ，二者不同时为1，相同时为0
	4）| , 按位或
	5）<< ,左移，符号位不变，高位丢弃，低位补0，左移一位相当于乘2，左移2位相当于乘4，以此类推左移n位 相当于乘2的n次方，这种计算比直接乘法要快很多
	6）>> ,右移，把运算数的各二进制位全部右移若干位，低位溢出，符号位不变，并用符号位补溢出的高位
		案例 1 : 5>>1
			5是正数，所以原码 反码 补码 都一样：0000 0101
			补码向右移动1位 ： 0000 0010 （低位溢出，高位用符号位0补位）
			结果：2
		案例 2 : -5>>1
			-5是负数，原码：1000 0101，反码：1111 1010，补码：1111 1011
			补码向右移动1位： 1111 1101 （低位溢出，高位用符号位1补位）
			补码：1111 1101 -> 反码： 1111 1100 ->原码：1000 0011
			结果：2

47、函数注意事项和使用细节
	1）函数的参数列表可以有很多个，也可以没有
	2）函数的名字遵循标识符的命名规则和规范
	3）函数中的变量是局部的，函数外不生效
	4）如果同一个文件出现两个函数名相同的函数，则以就近原则进行调用
		在python中可以定义两个相同的函数(函数名 和 参数个数都一样)
		从加载的顺序上看，下面的会覆盖上面的函数，也就是就近原则
		也就是说python是没有函数重载的
		如果定义了两个同名函数，但是参数不一样，调用时，函数的就近原则找到的函数体参数对不上，就会导致出错
		比如：
			def fun():
				...
			def fun(a):
				...
			fun()#此时函数的就近原则找到的时fun(a)这个函数，而该函数是需要参数的，因此会报错：TypeError
	5）调用函数的时候，根据函数定义的参数位置来传递参数，这种传参方式就是“位置传参”，传递的实参和定义的形参顺序和个数必须一致
	   同时定义的形参，不用指定数据类型，会根据传入的实参决定
	
	6) 函数可以返回多个类型的值，返回的数据类型不受限制
	
	7）函数支持关键字参数，函数调用时，可以通过"形参名=实参值"的形式传递参数
	   这样可以不受参数传递顺序的限制
	   
	8）函数支持默认参数/缺省参数
	   定义函数时，可以给参数提供默认值，调用函数时，指定了实参，则以指定为准，没有指定，则以默认值为准
	   默认参数，需要定义在参数列表后
	   
	9）函数支持可变参数/不定长参数
	   应用场景：当调用函数的时候，不确定传入多少个实参的情况
	   传入的多个实参，会被组成一个元组(tuple)，元组可以储存多个数据项，类似数组
	   
	10）函数的可变参数，还支持多个关键字参数，也就是多个“形参名=实参值”
		应用场景，当调用函数时，不确定传入多少个关键字参数的情况
		传入的多个关键字参数，会被组成一个字典(dict)，类似map,可以储存多个 key=value的数据项
		
	11）python调用另一个.py的函数
		需要使用import xx.py 导入文件

48、函数中字符串和数值类型的传参机制
	案例：/python_projects/PythonExam/06_函数/02_函数中字符串和数值类型的传参机制.py
	
	1)数值类型的传参机制
		形参和实参是同一个变量的地址，当形参被运算后，形参会重新指向新值的地址，形参的地址会变化，因此不会影响实参的值和地址
		和java不太一样，java是形参拷贝了实参的值，所以形参变化不会导致实参的变化
		
	2）字符串类型的传参机制
		和数值一样
		在java中string是对象引用，因此形参的值变化了，实参的值也会跟着变化
	
	原因：由于python的中字符串和数值都会被驻留机制影响，
		 因此即使形参在函数体内部进行了运算/重新赋值，变化的也只是形参变量的地址和值
		 但是都不会影响实参的地址和值
		 
		 字符串和数值类型都是不可变数据类型，当对应的变量值发生变化的时候，它对应的内存地址也会变化

		可变数据类型：当该数据类型的变量的值发生变化，如果他的内存地址不变，那么这个数据类型就是可变数据类型，包括 list,set,dict
		不可变数据类型：当该数据类型的变量的值发生变化，如果他的内存地址变了，那么这个数据就是不可变类型,包括：int,float，bool，string,tuple

73、继承
	案例:/python_projects/PythonExam/10_高级面向对象/02_继承.py
	
	继承基本介绍
		当多个类存在相同的属性和方法时，可以从这些类中抽象出父类，在父类中定义这些相同的属性和方法，所有的子类不要重新定义这些属性和方法。
	
	继承的基本语法
		class DerivedClassName(BaseClassName):
			...
			
		DerivedClassName是子类的类名，BaseClassName是父类的类名
		子类自动拥有父类的属性和方法，非私有的属性和方法可以在子类直接访问，但是私有属性和方法不能在子类直接访问，要通过父类的提供的共有方法才能访问
		和java一样python也有个object类，它是所有类的基类
		子类的属性和方法和父类的属性和方法重名的时候，在子类实例中，优先使用子类的属性和方法
		
	多重继承
		python支持多重继承
		class DerivedClassName(Base1,Base2,Base3):
			....
		在多重继承中，如果有同名的成员，遵守从左到右的继承优先级（即：写在左边的父类优先级高，右边的低）
		
	调用父类的构造器
		在子类构造器中可以调用父类的构造器，完成子类初始化的工作，
		如果子类没有定义自己的构造器，初始化子类对象时，会自动使用父类的构造器
		语法：super().__init__(参数列表)
		
	父类成员的调用
		如果子类和父类出现同名的成员，可以通过父类名、super()访问父类的成员
		
		方式一：父类名.成员变量/成员方法(self,[参数列表])，表示从某个父类开始向上找
		方式二：super.成员变量/成员方法([参数列表])，表示从直接父类开始向上找，推荐使用，因为一旦父类名变化，类名统一都要修改，比较麻烦
		
		子类不能直接调用父类的私有成员
		访问不限于直接的父类，而是建立从子类向上级父类的查找关系 A->B->C
		
	方法的重写
		python不支持重载，但是支持重写
		即子类继承父类的属性或方法后，根据业务需要，再重新定义同名的属性或方法

74、类型注解
	案例:/python_projects/PythonExam/10_高级面向对象/03_类型注解.py

	type hint,类型注解：类型注解提示是可选的而不是python的强制要求，但他们对静态类型检查器很有用处，他们还能帮助IDE实现代码补全与重构
	
	它最主要的作用是对类型的提示
	
	随着项目越来越大，很容易记不住某一个方法的参数类型是什么，一旦传错，只能再运行时刻才能检查出来，这对项目来说是巨大的灾难
	从3.5开始，引入了类型注解机制
		1）类型提示，防止运行时出现参数类型，返回值类型，变量类型不符合
		2）作为开发文档的附加说明，方便使用者调用时传入和返回参数类型
		3）加入后不会影响程序的运行，不会报正式的错误，只有提醒
		4）Pycharm之类的高级IDE，参数类型会高亮提示
		
	注解简介：
		def fun1(a:str):
			...
		a:str，表示a参数的类型要求是字符串类型的
		
	注解在使用的时候主要分三种情况
		1）变量类型的注解
			基本语法:变量:类型，比如 num:int = 10,使用该注解后，再给num赋值其他类型的值，会有错误提示
			
			容器详细类型注解，如果变量是容器，并且想对容器中的元素进行注解，可以使用如下方式
				list1:list[int],表示容器是保存整数的list
				dict1:dict[int,str] = {1:"一",2:"二"},表示该变量是字典类型，并且字典的key是整形，value的类型是字符串
				
			在注释中使用注解
				num = 98.1 #type:float
				dict2={} #type:dict[int,str]
				
		2）函数的类型注解
			def 方法名(形参1:类型，形参2:类型...) -> 返回值类型:
				方法体
				
			例如：
			def sumNums(num1:int, num2:int) ->int:
				return num1 + num2		
			
			#该方法没有返回值
			def printInfo(text:str) -> None:
				print(text)			
				
		3）Union类型
			联合类型，Union[x,y] 等价于 x|y,意味着满足x或y之一
			它可以定义联合类型注解
			在变量，函数都可以使用Union类型注解
			使用前，需要先导入Union: from typing import Union
			
			基本语法：Union[类型1，类型2，...]
			比如 a:Union[int, float,str] = 'abc' 表示a变量可以是int,float,str三种类型都可以
	
75、多态
	案例：/python_projects/PythonExam/10_高级面向对象/04_多态.py
	
	多态，是不同的对象调用相同的方法，表现出不同的状态，称为多态
	python中，多态通常作用在继承关系上
	比如：一个父类，具有多个子类，不同子类调用相同的方法，执行的时候产生不同的状态，就是多态
	
	在python面向对象中，子类对象可以传递给父类类型的参数
		def person_work(person: Person):
			person.work()
		
		teacher = Teacher('李老师')
		student = Student('小明')
		person_work(teacher)
		person_work(student)
		
	多态的好处：
		1）增加了灵活性，不论对象如何变化，使用者都是同一形式取调用
		2）增加了扩展性，通过继承父类得到的子类，使用者无需更改自己的代码
	
	python的多态特点
		1）python中的函数的参数是没有类型的，所以多态在python上体现的并不是很严谨（比如java这种强类型语言）
		2）python不要求严格的继承体系，关注的不是对象的类型本身，而是对象是否有要调用的方法/属性
		
	isinstance(),用于判断对象是否是某个类或者子类的对象
	基本语法：isinstance(object,classinfo),classinfo可以是类名，基本类型或者由他们组成的元组
		
		num = 9.9
		print(f"num 是否是str/int/list对象：{isinstance(num,float)}")
		
		#也可以判断是否是多个类型的某一种
		print(f"num 是否是str/int/list对象：{isinstance(num,(str,int,list))}")
		
76、魔术方法
	案例：/python_projects/PythonExam/10_高级面向对象/05_魔术方法.py
	
	1）在pythons中所有以双下划线__包起来的方法，统称为Magic Method（魔术方法）。
	   它是一种特殊的方法，普通方法需要调用，而魔术方法不需要调用就可以自动执行。
	
	2)魔术方法在类或者对象的某些事件发生时会自动执行，让类具有神奇的“魔力”。如果希望自己的程序定制特殊功能的类，那么就需要对这些方法重写。
	
	3）python中常用的运算符，for循环，以及类操作等都是运行在魔术方法之上的。
	
	4）常见的魔术方法:
		__init__,初始化类对象的时，自动调用
		__str__(self)，定义为对象转字符串行为，类似java的toString()方法
			           输出一个对象时，默认输出的是类型名+对象内存地址(父类object的__str__(self)方法)
					   子类往往重写__str__,用于返回对象的信息
					   重写后，print(对象)，或str(对象)时，都会自动调用该对象的__str__
		__eq__(self,other)，定义等号行为：x==y，默认情况下对象的等操作，判断的是对象的地址

78、抽象类:
	案例:/python_projects/PythonExam/10_高级面向对象/07_抽象类.py
	
	默认情况下,python不提供抽象类，Python附带一个模块，该模块为定义抽象基类提供了基础，该模块称为:abc
	当我们需要抽象基类的时候，继承ABC（abc模块的AB类），使用@abstractmenthod声明抽象方法，那么这个类就是抽象类
	抽象类的价值更多作用是在于设计，是后者设计好以后，让子类继承并实现抽象类的抽象方法
	注意抽象类是不能实例化的，强行实例化会报错：
		TypeError: Can't instantiate abstract class Person without an implementation for abstract method 'start_work'
	
		from abc import ABC, abstractmethod
		
		class Person(ABC):
			__name = None
		
			def __init__(self, name):
				self.__name = name
		
			def get_name(self):
				return self.__name
		
			#定义抽象方法，注意方法体需要pass来占个位，保证解释器能正常执行
			@abstractmethod
			def start_work(self):
				pass
		
		class Student(Person):
			#在IDE中，如果没有实现抽象方法，会有提示，在类上 more_action中，选择实现抽象方法即可
			def start_work(self):
				print(f"Student {self.get_name()} start studying")
		
			def __init__(self, name):
				super().__init__(name)
		
		class Teacher(Person):
			def start_work(self):
				print(f"Teacher {self.get_name()} start classing")
		
			def __init__(self, name):
				super().__init__(name)
		
		student = Student("tom")
		teacher = Teacher("luch")
		student.start_work()
		teacher.start_work()	
		
	抽象类的使用注意事项：
		1）抽象类不能实例化
		2）抽象类中至少要有一个抽象方法
		3）抽象类中可以有普通方法，静态方法。
		4）如果一个类继承了一个抽象类，它必须实现抽象类中的所有抽象方法，否则它依然是一个抽象类

82、异常处理
	案例:/python_projects/PythonExam/11_错误和异常/03_异常处理.py
	
	异常处理就是当异常发生时，对异常处理的方式
	语法：	
		try:
			可能出现异常的代码
		except [异常1 as 别名]:
			异常1发生时，对异常处理的代码
		except [异常2 as 别名]:
			异常2发生时，对异常处理的代码	
		...
		[else:]
			没有发生异常，执行的代码
		[finally:]
			不管有没有异常，都要执行的代码，比如关闭资源
	
	注意事项和使用细节
		1）如果异常发生了，那么异常后面的代码都不会执行，直接进入到except字句
		2）如果异常没有发生，则顺序执行try的代码块，不会进入到except字句
		3）如果希望没有发生异常的时候，要执行某段代码，则使用else字句
		4）如果希望不管有没有异常发生都要执行的代码，可以放到finally中执行
		5）可以有多个except字句，捕获不同的异常进行不同的业务处理，如果发生异常只会匹配一个except，建议把具体的异常放在前面，基类异常放在后面
		   这样当具体异常没有捕获到的时候，再由基类捕获
		6) 一个except也可以捕获多个异常,当某一个异常被匹配的时候就会被捕获
			例如：
				try:
					...
				except (ValueError,ZeroDivisionError) as e:
					...

101、进程池
	
	无限制的创建进程完成任务，有可能造成内存压力，效率也不一定会有提升，比较好的方式是使用进程池
	
	进程池中的进程是循环利用，如果进程不够，进程池会自动创建进程，如果进程满了，任务会等待，直到有进程空闲
	
	进程池创建执行独立任务
		案例：/python_projects/PythonExam/13_多任务并发操作/11_进程池独立任务.py
		with ProcessPoolExecutor(2) as pool:
			for i in range(5):
				pool.submit(fun,i)#第一个参数是函数名，后面按照顺序填入函数的实参
			#等待进程池中所有进程都执行完毕，再继续执行
			pool.shutdown(True)
		
	进程池回调
		案例：/python_projects/PythonExam/13_多任务并发操作/12_进程池任务回调.py
		如果进程池的任务需要把数据回调给主进程，需要设置一个回调接口
			p = pool.submit(task,i)
			p.add_done_collback(callback函数名)
		
		#注意，因为要回调给主进程，doTask应该有return,没有return，返回的是None
		def doTask(_id):
			print(f"{os.getpid()}进程开始执行{_id}号任务")
			time.sleep(random.random() + 0.1)
			return random.randint(1,100)
		
		#任务结束时的回调方法，_result中封装了返回值
		def taskDone(_result):
			print(f"任务完成，结果是：{_result.result()} {multiprocessing.current_process().name}")
		
		if __name__ == '__main__':
			pool = ProcessPoolExecutor(max_workers=4)
			for i in range(10):
				p = pool.submit(doTask, i)
				p.add_done_callback(taskDone)#注意：回调函数是在主进程中调用的
			pool.shutdown(True)
		
	进程池中使用进程锁
		案例：/python_projects/PythonExam/13_多任务并发操作/13_在进程池中使用锁.py
		
		在进程池中要使用进程锁，需要基于Manager中的Lock和RLock来实现
		
		def fun(d,_lock):
			for i in range(10000):
				with _lock:
					d['num'] += 1
			print(f"{os.getpid()} 任务完成")
		
		if __name__ == '__main__':
			pool = ProcessPoolExecutor(max_workers=4)
			lock = multiprocessing.Manager().RLock()
			with multiprocessing.Manager() as manager:
				d = manager.dict()
				d['num'] = 0
				for i in range(10):
					pool.submit(fun, d,lock)
				pool.shutdown(True)
				print(f"所有任务完成，结果是{d['num']}")		

102、GIL锁
	GIL锁，全局解释器锁(Global Interpreter Lock),是CPython解释器中特有的一种锁机制，让一个进程同一个时刻只能有一个线程被CPU调用
	也就是说python中线程是不能并行执行的，只能并发执行，因此python中多线程是不能支持多核CPU的。
	
	如果程序想利用计算机的多核优势，让CPU同时处理一些任务，适合用多进程开发(开销会比较大)
	如果不想用多核优势，可以考虑使用多线程开发，python中线程是不支持多核CPU的
	
	常见的程序开发中，计算操作需要使用CPU多核优势，IO操作不需要利用多核优势
		计算密集型，用多进程，例如：大量的数据计算
		IO密集型，用多线程，比如读写文件/数据库，网络数据传输等
	
103、多线程开发
	案例:/python_projects/PythonExam/13_多任务并发操作/14_python多线程开发.py
	
	进程是分配资源的最小单位，一旦创建一个进程就会分配一定的资源。
	线程是程序执行的最小单位，实际上进程只负责分配资源，而利用这些资源执行程序的是线程。
	也就是说进程是线程的容器，一个进程最少有一个线程来负责执行程序，同时线程不拥有系统资源，只需要一点在运行中必须的资源。

		2）通过线程类创建线程对象

		3)线程启动
			t.start()，#当前线程已经准备完毕，等待CPU调度
		线程参数：
			target，执行的目标任务名，这里指的是函数名
			name，线程名，一般不用设置
			gruop，线程组，目前只能使用None
			
	t.join(),当前线等待子线程结束后再继续执行
		如果批量创建线程可以都start以后再一起join，这样即能保证多个线程可以同时运行，也可以保证所有线程都执行完毕后再继续执行

	pythons中提供了两种锁
		
		同步锁
			threading.Lock()

		递归锁

109、进程和线程对比
	1）线程时依附在进程里面的，没有进程就没有线程
	2）一个进程默认提供一条线程，一个进程内可以创建多个线程
	3）创建进程的资源开销要比创建线程的资源要大
	4）进程时操作系统资源分配的基本单位，线程时cpu调度的基本单位
	5）线程不能独立运行，必须依附于进程
	6）进程的优点是可以真正的使用CPU的多核特性，但是开销比较大
	7）线程的优点是，资源开销比较小，但是不能使用多核(注意：因为GIL锁机制，所以python中的线程是不支持多核CPU的)

110、协程
	案例:/python_projects/PythonExam/13_多任务并发操作/20_协程.py
	
	协程(Coroutine),是程序员通过代码搞出来的一个东西
	也可以称为微线程，是一种用户态内的上下文切换技术，简而言之，协程就是通过一个线程实现代码块相互执行(来回跳着执行)
	
	python中有多种方式可以实现协程，例如：greenlet
		pip install greenlet
	
	协程主要在IO操作时，高效利用等待时间，当需要等待IO操作的时候可以执行其他函数的某些内容，从而提升单线程的效率
	比如下载100张图片，如果并发使用线程池，可能同时要开10个线程并发操作
	也可以使用单线程，第一个函数开始发送网络请求遇到阻塞，就立即执行第二个函数调用，这样一个线程就可以同时发送100张图片的请求，那张先回来，就继续执行
	
	通常比较好的方式是让协程发送io请求(比如网络请求)，等数据回来以后，当需要大量运算的时候，可以使用进程继续执行后面的任务
	
	python 3.4之后推出了asyncio模块 + python3.5推出的async语法，内部基于协程并且遇到IO请求自动化切换，提升效率
	
	协程可以更加提升线程的利用率，更加节省资源
	通常系统有频繁的io请求，希望能更极致的发挥系统资源，可以考虑协程
	
	目前很多python中的框架都支持协程，比如：FastAPI,Tornado,Sanic,Django 3,aiohttp等
