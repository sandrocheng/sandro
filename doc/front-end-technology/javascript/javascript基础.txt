2、js简介
	案例：\javascript_projects\javascript_exam_project\01-js体验\01体验.html

	js是一种运行在客户端(浏览器)的编程语言，实现人机交互。

		1）ECMAScript,js语言基础：

		2）Web APIs:
			DOM，页面文档对象模型，用来操作文档，比如页面元素进行移动，大小，添加删除等操作。
			BOM，浏览器对象模型，用来操作浏览器，检测窗口宽度，存储数据到浏览器等等。
			
3、javascript的书写位置
	1）行内js
		案例：\javascript_projects\javascript_exam_project\01-js体验\02内行书写位置.html
		直接在html文件里，用script标签包住
		规范：通常script标签写在</body>上面
		原因：将script标签放在html文件的底部附近的原因是浏览器会按照代码在文件中的顺序加载html
		     如果先加载的js期望修改其下放的html，那么它可能由于html尚未加载二失败
			 因此，将js代码放在html页面的底部附近通常是最好的策略
		
	2）内链js
		代码卸载html标签内部
		比如：<button onclick="alert('success')">点击</button>

	3）外部js
		代码写在以.js结尾的文件里，外部js引入使代码更加有序，更易于复用，且没有了脚本的混合，html更加易读
		通过script标签，引入到html文件中，注意这个时候script标签内部就不能写js代码了，写了也没用
		案例：\javascript_projects\javascript_exam_project\01-js体验\03外部js书写位置.html

5、js的输入输出语法
	案例：\javascript_projects\javascript_exam_project\01-js体验\04js的输入和输出.html
	输出：
		1）document.write('要输出的内容')
		   向body内输出内容，注意：如果输出的是标签，也会被解析成网页元素
		   
		2) alert('xxx'),弹出框输出内容
		
		3）console.log("控制台输出")，在控制台输出，主要给程序员使用
			‌console.log 是 JavaScript 中用于在浏览器或 Node.js 控制台输出调试信息的核心方法‌，支持输出变量、对象、字符串等多种数据类型，并可通过格式占位符实现样式化输出。‌
	
			3.1)基础输出‌：直接传入参数即可打印内容，例如 console.log("Hello") 输出字符串，console.log(42) 输出数字。‌‌
	
			3.2)格式占位符‌：通过占位符控制输出格式，需与后续参数一一对应：
				%s：字符串（如 console.log("%s", "text")）。‌‌‌‌
				%d 或 %i：整数（自动截断小数部分）。‌‌
				%f：浮点数（保留小数）。‌‌
				%c：CSS 样式（如 console.log("%cStyled Text", "color: red; font-size: 16px")）。‌‌
				%o 和 %O：对象输出（%O 以树状结构显示完整属性）。‌‌
		
			3.3)‌多参数处理‌：若参数为对象或数组，log 方法会直接输出其结构，避免 alert 的 [object Object] 问题。‌‌

			3.4)console 提供多种日志级别方法，适用于不同场景：
				console.info()：与 log 类似，但部分浏览器标记为“信息”图标。‌‌
				console.warn() 和 console.error()：分别输出警告和错误信息，并附带堆栈跟踪，便于问题定位。‌‌
				console.debug()：输出调试信息，默认在控制台“Verbose”级别显示。‌‌
		
			3.5)结构化输出
				console.table(data)，以表格形式展示数组或对象，支持字段排序
		
			3.6）性能分析
				console.time("计时器") 和 console.timeEnd("计时器")：测量代码块执行时间。‌‌
				console.count("标签")：统计代码执行次数。‌‌
			3.7)分组日志
				console.group("标签") 和 console.groupEnd()：，便于分类查看（如 console.group("用户数据") 后接多条 log）。‌‌
		
	
	输入:
		语法：prompt("请输入xxxx")
		作用：显示一个对话框，对话框中包含一条文字信息，用来提示用户输入文字

	案例：\javascript_projects\javascript_exam_project\02-变量\01变量的声明和使用.html
	计算机用于存储数据的“容器”
	
	js变量的声明/创建/定义：
		语法：let 变量名
		声明变量有两部分构成：声明关键字、变量名
		let即关键字
	
	变量赋值
		定义变量后，就可以对其初始化(赋值)，在变量之后跟上“=”,然后是值
		比如：age = 18
	
	变量的初始化
		在变量定义的时候直接赋值
		比如：let name="张三"
		
	变量的更新
		变量可以重新赋值
		比如：age = 19
		注意：在同一个作用域下，不能使用let重复声明同名的变量
		
	声明多个变量，简写
		比如: let age=20,name="张三"
		虽然这么写看上去代码更短，但是不推荐这么写，为了更好的可读性，最好一行只声明一个变量
	
	获取prompt输入
		age = prompt("请输入年龄")
		
	变量值的交换
		let a=1,b=2
		let temp = b
		b = a
		a = temp
	
	js变量定义的规则
		1)不能使用js关键字定义变量名，比如： let、var、for、if等
		2）变量名只能使用下划线，字母，数字，$组成，且数字不能放在开头
		3）字母严格区分大小写，如：Age和age是两个不同的变量
	js变量定义的规范
		1）起名要有意义
		2）推荐小驼峰命名法
	
	let和var的区别
	旧版本的js语法，使用关键字var来声明变量，而不是let
	var目前已经很少使用，
	let解决了var很多不合理的地方，比如var可以重复定义变量名，可以先使用，后声明，变量提升，全局变量，没有块级作用等等
	总之，var已经不适合新版本js的编码，尽量不要使用

11、数据类型
	案例：\javascript_projects\javascript_exam_project\02-变量\04数据类型.html
	
	js数据类型分为两大类
		1）基本数据类型
			number,数字类型，可以是整数，小数，整数，负数，数字类型的数据可以进行加(+),减(-)，乘(*)，除(/),取模(%)运算
				   优先级越高越先被执行，优先级相同时从左向右执行
				   乘法，除法，取模，优先级相同
				   加法，减法，优先级相同 
				   乘法，除法，取模的优先级大于加法和减法
				   使用()可以提升优先级
				   NaN，not a number,代表一个计算错误，他是一个不正确的或者一个未定义的数学操作得到的结果，比如 “tony” - 2,
				       Nan是粘性的，NaN和任何类型运算都返回NaN,比如：Nan + 2
					   
			string,字符串类型
			       通过双引号，或者单引号包裹的数据都是字符串或反引号（``），单引号和双引号没有本质上的区别，推荐使用单引号
				   引号可以互相嵌套，但是不可以自己嵌套自己，
						比如： let word = '我是"张三"'
				   必要时可以使用转义符'\'输出单引号或双引号，比如：str = '我是\'张三\''
				   字符串可以使用"+"进行多个字符串的拼接，字符串和任意类型的数据使用"+"链接都是字符串
				   
			boolean,布尔型，使用 true,false 作为赋值的字面量，通常也可以用数字0代表false,非零代表true
			undefined，未定义类型，只声明变量，但是不复制的情况下，变量的默认值就是undefined，一般很少直接为某个变量赋值为undefined
					   因为js只有赋值之后才知道变量的类型，因此不赋值的情况下，值是undefined而不是null
					   通常在函数中，形参可以通过判断是否是undefined来判断调用者是否有传递参数过来
			null,空类型，null代表赋值了，但是内容为空
				官方解释，把null作为尚未创建的对象,所以null实际上是一个对象
				注意:undefined 和其他变量/常量/字面量进行数学运算，是没有结果的 NaN
					null 和其他类型的变量进行数学运算，相当于0和其他变量进行运算
					null 和 undefined和字符串进行拼接，相当于字面量和字符串拼接
						比如 null + 'lily' //值是 : nulllily
						    undefined + 'lily')//值是 : undefinedlily
		2）引用数据类型
			object,对象
	
	注意：js是弱数据类型，即变量到底属于哪种类型，只有赋值之后，我们才能确认
	     因此变量在初始化后，还可以继续赋值为其他类型的值 
		 
	数据类型的检测
		通过typeof关键字检测
		1）作为运算符： typeof x //常用写法
		2）作为函数：typeof(x)

13、数据类型的转换
	案例：\javascript_projects\javascript_exam_project\02-变量\06数据类型的转换.html
	
	js中常通过表单，prompt等组件获取数据,而这些数据默认是字符串类型的，此时不能直接进行数学运算，需要进行类型转换才能得到正确值
	
	隐式转换
		某些运算符被执行时，系统内部自动将数据类型进行转换
		规则：
			+号两边如果有一个是字符串，都会把另外一个转成字符串
			除了+以外的算数运算符，比如 - * /等都会把数据转成数字类型
		缺点：
			转换类型不明确，靠经验才能总结
		小技巧：
			+号作为正号解析可以转换成数字类型
				比如：    
					str = '100'
					num = +str
					此时num已经是数字类型了
			任何数据和字符串相加结果都是字符串
	
	显示转换
		编写程序时，过度依赖隐式转换是不严谨的，因为隐式转换并不清晰，大多是靠经验总结的规律
		为了避免隐式转换带来的问题，js提供了显示转换的方式
		1）Number(数据)，转换为数字类型
		   如果数据无法转换成字符串，返回NaN,即不是一个数字
		   NaN也是number类型的数据，代表非数字
		   
		2）parseInt(数据)，只保留整数，parseInt和Number的区别是，他会把数据中的数字提取出来，返回一个整数
						 提取的方式是从第一个字符开始提取，直到不是数字的字符为止，如果第一个字符就不是数字，则返回NaN
		3）parseFloat(数据)，可以保留小数

15、比较运算符
	案例：javascript_projects\javascript_exam_project\03-运算符\02-比较运算符.html
	
	常用比较运算符
		>,
		<,
		>=,
		<=,
		==,左右两边的值是否相当，在js中 字符串类型和数字类型是可以比较的，比如 "123"是等于123的
		===,左右两边是否类型和值都相等
		!==，左右两边是否全不等
	>,< ,>=,<=,==有隐式转换的作用，如果字符串是数字的，他会先转换为数字类型的值再比较
	
	注意：
		在js中，undefined和null的值是相等的，因此==返回的值是true,但是类型不一样，因此===返回的是false
		NaN 和 NaN的值不相等，类型也不相等，也就是说NaN不等于任何对象，包括它自己
	
		开发过程中判断是否相等，推荐使用===或者 !==
	
		字符串的比较，实际上比较的是ASCII码
		
		尽量不要比较小数，因为小数有精度的问题，可能结果是错误的，如果一定要比较，最好先转换成整数，在比较

16、逻辑运算符
	案例：\javascript_projects\javascript_exam_project\03-运算符\03-逻辑运算符.html
	
	逻辑运算符通常用于多重条件判断
	&&，逻辑与
	||，逻辑或
	!，逻辑非
	
	逻辑中断/短路：
		只存在于&& 和 || 中，当满足一定条件会让右边的代码不执行
		&& ，左边为false,就短路，如果两侧都是真值，则返回最有一个真值
			比如 x = 1 && 2// 因为两侧都是真值，则返回最后一个真值（2）
		|| ，的左边为true就短路	,如果左右都为假，则返回最后一个假值
	
	在逻辑运算中，'',0,undefined,null,false,Nan转换为boolean值后都是false,其余为true

18、表达式和语句的概念
	表达式：可以求值的代码，叫做表达式
	语句：是一段可以执行的代码，它不一定有结果
	区别：因为表达式可以求值，所以可以放到赋值语句的右侧
		 语句不一定有值，没有值的语句不能放到赋值语句的右侧
	在某些情况下，也可以把表达式理解为一个表达式语句，因为它在计算结果，但不是必须的成分

23、switch语句
	案例：\javascript_projects\javascript_exam_project\04-程序控制结构\03-switch语句.html
	
	语法：
		switch(数据){
			case 数值1：
				...
				break
			case 数值2:
				...
				break
			case ...
				break
			default:
				...
				break
		}
		找到全等的值，并执行对应的代码
		若没有全等的值===，则执行default里的代码
		
		switch通常用于等值判断，不适用与区间判断
		通常需要break配合，否则会造成case 穿透
		
		通常，分支比较少的时候，if..else效率比较高，如果分支比较多(大于5个)，switch效率比较高

30、数组元素的操作	
	案例：\javascript_projects\javascript_exam_project\05-数组的操作\02-数组元素的操作.html
	
	元素的修改和增加
		数组[下标]=新值
	
	注意，如果数组[下标]没有值，则会在该下标下增加新的数据，有值则会修改
	数组长度是有值的最大下标+1,其他没有赋值的下标对应的元素的值是undefined	
	
	元素的增加，除了通过下标增加数据以外，js数组还提供了两个添加元素的接口函数
		1）arr.push(元素1，元素2，。。。)，在数组的结尾处增加一个或多个新元素，该方法返回数组的长度
		2) arr.unshift(元素1，元素2，。。。)，在数组的头部增加一个或多个新元素，该方法返回数组的长度
	
	元素的删除
		1)arr.pop()，删除数组中的最后一个元素，并且返回该元素的值
		2)arr.shift()，删除数组中第一个位置的元素，并返回该元素的值
		3)arr.splice(下标，删除的个数)，从下标的起始位置开始删除指定个数的元素，如果指定元素超过数组剩下的长度也没关系，相当于把数组后面的元素全删除了。
			如果不指定删除的个数，该方法会把从下标位置开始的元素全部删除。

	数组的排序
		1）arr.sort(),升序排序
		2）降序排序：arr.sort(function(a,b){
			return b-a //a-b，就是正序排序，返回值大于零交换，小于等于零不交换，比如返回-1，则相当于数组反转
		  })
31、函数的基本使用
	案例：\javascript_projects\javascript_exam_project\06-函数\01-函数的基本使用.html
	
	js函数，被设计为执行特定任务的代码块，比如alert(),prompt(),console.log()等
	
	函数声明语法：
		function 函数名(){
			函数体
		}
		函数命名尽量小驼峰命名法，前缀应该为动词
	
	函数的调用语法：函数名()
	函数不调用自己不执行，函数一次声明，可以多次调用
	
	函数体：函数体是函数的构成部分，它负责将相同或者相似的代码包裹起来，直到函数调用时，函数体内的代码才会被执行。函数的功能代码都要写在函数体中。
	
32、函数的参数
	案例：\javascript_projects\javascript_exam_project\06-函数\02-函数的参数.html
	
	若函数完成功能需要调用者传入数据，那么就需要用有参数的函数
	
	声明语法：
		function 函数名(参数1,参数2...){
			函数体
		}
	
	实参：实际的参数，他是函数调用时，写载函数参数列表中实际的值，也可以是变量
	形参：函数的参数列表中的参数，叫形参
	形参可以理解为在函数内声明的变量，实参可以理解为给这个形参赋值
	
	如果函数调用没有传递实参，形参的值就是undefined
	为了避免没有传递参数导致的错误，可以给形参定义默认值，让程序更严谨
		function 函数名(参数1=默认值1，参数2=默认值2...){
			函数体
		}
	这个默认值只会在缺少实参传递时才会被执行，多有参数会优先执行传递过来的实参，否则默认undefined
	
32、函数的返回值
	案例:\javascript_projects\javascript_exam_project\06-函数\03-函数的返回值.html
	
	返回值概念：当调用某个函数，这个函数会返回一个结果出来，函数可以有返回值也可以没有返回值。
	
	当函数需要返回数据给调用者时，需要用到return关键字
	
	有返回值的函数：
		1）在函数体中使用return关键字能将内部的执行结果交给函数外部使用
		2）return后面代码不会再被执行，会立即结束当前函数，所以return后面的数据不要换行写
		3）函数可以没有return，这种情况下函数默认返回undefined

33、函数总结
	1）函数名相同的时候，后面的函数会覆盖前面的函数（js没有函数重载）
	2）在js中，实参的个数可以和形参的个数不一样
		如果形参过多，会自动填上undefined
		如果实参过多，那么多余的参数会被忽略，函数内部会有一个arguments，里面保存着所有的实参
	3）函数一旦遇到return，就不会再继续执行了

34、作用域
	通常来说，一段程序代码中所用到的名字并不重视有效和可用的
	限定这个名字的可用性的代码范围就是这个名字的作用域。
	
	作用域的使用提高了程序逻辑的局部性，增强了程序的可靠性，减少了名字冲突
	
	1）全局作用域
		作用于所有代码执行的环境(整个script标签内部)，或者一个独立的js文件
		全局变量：函数外部使用let定义的变量，全局变量在任何区域都可以访问和修改
	2）局部作用域
		作用于函数内部的代码环境，就是局部作用域。因为跟函数有关系，所以也称函数作用域
		局部变量：函数内部使用let定义的变量，它只能在当前函数内部访问和修改
		如果函数内部，变量没有使用let声明，直接赋值，也当全局变量来看，前提是函数必须要调用一下，但是强烈不推荐这么写
		函数内部的形参也是局部变量
		
	在不同作用域下，可能存在相同的变量名，这时对变量的访问使用就近原则，即先局部后全局
	
35、匿名函数
	案例:\javascript_projects\javascript_exam_project\06-函数\04-匿名函数.html
	
	函数分为两大类：
		1）具名函数，有名字的函数，也就是最常用的函数
		2）匿名函数，没有函数名的函数，比如: function (){}。
	
	匿名函数的使用
		1）函数表达式
			把匿名函数赋值给一个变量，并且通过变量名称进行调用 我们将这个称为函数表达式。
			比如：
			let fun = function(x,y){
				//函数体
			}
			fn(1,2)// 通过变量名 + ()的方式调用
			
			函数表达式和具名函数的区别：具名函数可以在任意地方调用，函数表达式限于变量的作用域，不能任意使用，必须先声明再调用。
			在js开发中 事件类的函数常常使用函数表达式来实现，比如点击事件等
			
		2）立即执行函数
			使用场景：避免全局变量之间的污染,注意，立即函数后面要加分号，否则会让后面的代码出错
			案例1:
				(function(x){
					console.log("立即执行 " + x)
				})();
			案例2:
				(function(x){
					console.log("立即执行 ： " + x)
				}());
			
			立即执行函数的好处：
				在封装js的时候，代码用一个立即执行函数包裹起来，这样当引用者引用的时候，就不必担心当前js中的变量会和其他的js变量重名导致的问题了
				比如：
					a.js:
					function(){
						let name = "xxx"
					}();
					
					b.js:
					function(){
						let name = "yyy"
					}();
					
					如果 a.js 和 b.js 同时被某个html页面引用，那么这里面的 name会因为重名导致变量数据冲突，分别放到不同的立即执行函数中，就能避免该问题。
					
36、对象的基本使用
	案例：\javascript_projects\javascript_exam_project\07-对象\01-对象的基本使用.html
	
	对象(object)，js里的一种数据类型，可以理解为一种无序的数据集合，通常用于描述一个事务
	例如: let user = {
			name:'lily',
			age:18,
			gender:'女'
		}
		
	对象中可以有：
		静态特征：可以使用数字，字符串，数组，布尔类型等类型表示
		动态行为：可以使用函数表示
	
	对象声明： 
		let 对象名 = {}
		let 对象名 = new Object()
		实际开发中，我们多用{},{}是对象字面量
		
	对象由属性和方法组成：
		比如：
		let 对象名 = {
			属性名:属性值，
			方法名:函数
		}	
		
	属性：
		属性都是成对出现的，包括属性名和值，它们之间使用英文:分隔
		多个属性之间使用英文,分隔
		属性就是依附在对象上的变量(外面是变量，对象内叫属性)
		属性名可以使用""或''包裹，一般情况下省略，除非名称遇到特殊符号如空格，中横线等
		属性的名称通常不要使用"name"，这会和系统的属性冲突
	
	访问对象属性值
		1）通过 对象.属性 获取对象的某个属性值
		2）通过 对象.属性 = 新值 来重新给属性赋值
		3）通过 对象["属性名"]来访问对象属性，这种方式通常用于属性名中带有特殊符号无法使用"对象.属性名"来访问的情况
	
	对象的动态添加属性
		通过 对象.新属性 = 新值 来给对象新增属性
	
	对象属性的删除
		delete 对象名.属性

38、遍历对象
	案例:\javascript_projects\javascript_exam_project\07-对象\03-遍历对象.html
	
	遍历对象是指遍历所有对象中的属性名(也包括方法名)
	对象里面是无序的键值对，没有规律，不像数组里面有规律的下标可以使用
	通过for ... in ... 语法 来遍历所有对象属性
		for (let k in user) {
			console.log(`${k} = ${user[k]}`)
		}		
		
	for ... in ...语法,也可以用来遍历数组，但是注意：返回的是下标，并且该下标是字符串类型
		arr = ['大连', '沈阳', '抚顺', '本溪']
		for (let index in arr) {
			console.log(`${index} = ${arr[index]} , index type is ${typeof index}`)
		}
	
	通常不推荐使用for...in语法来遍历数组

42、数据类型
	js中的数据类型分为基本数据类型和引用数据类型两种
	1）基本数据类型，也叫值类型，或者简单数据类型
	   基本数据类型，在存储时，变量中保存的时值本身，因此叫值类型，比如 string,number,boolean,undefined,null
	   
	2）引用数据类型，也叫复杂类型
	   在存储的时候，保存的是内存地址
	   通常通过new关键字创建的对象(系统对象，自定义对象)，如：Object,Array,Date等
	   
43、堆空间与栈空间
	1）栈(操作系统)：由操作系统自动分配释放存放函数的参数值，局部变量的值等。其操作方式类似于数据结构中的栈
		简单数据类型存放在栈中
	2）堆(操作空间)：存储复杂类型（对象），一般由程序员分配释放，若程序员不释放，则由垃圾回收机制回收。
	   复杂数据类型的对象变量里保存的是地址，该地址指向的是堆空间中的实际数据。
	  
	js本身并没有明确的堆，栈区分，但是可以借助这个思想理解js是如何保存值类型和引用数据类型的数据。
