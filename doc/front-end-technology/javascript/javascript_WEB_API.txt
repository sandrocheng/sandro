1、WEB_API
	作用：就是使用js去操作html和浏览器
	分类：
		1）DOM,文档对象模型，比如对页面元素的增删改查等API接口
		2）BOM,浏览器对象模型，比如alert,prompt就是操作浏览器的API接口

2、DOM
	Document Object Model,文档对象模型
	是用来呈现以及于任意HTML或XML文档交互的API，DOM是浏览器提供的一套专门用来操作网页内容的功能
	DOM的作用：开发网页内容特效和实现用户交互
	
3、DOM树
	将HTML文档以树状结构直观的表现出来，我们称之为文档树或DOM数
	描述网页内容关系的名词
	作用：文档树直观的体现了标签于标签之间的关系
	比如：
		document
			--->HTML
				--->head
					--->meta
						--->...
					--->title
						--->...
					--->...
				--->body
					--->文本
					--->div
						--->id
						--->class
						--->文本
					--->a
						--->href
						--->链接名
					--->...
	DOM中，最顶层的节点是document，然后是HTML页面以及其内容

4、DOM对象
	浏览器根据html标签生成的js对象
		1）所有的标签属性都可以在这个对象上找到
		2）修改这个对象的属性会自动映射到标签身上
	
	DOM的核心思想
		把网页内容当作对象来处理
	
	document对象
		1）是DOM里提供的对象，也是当前页面最大的对象
		2）所以它提供的属性和方法都是用来访问和操作网页内容的
			比如：document.write()
		3)网页所有内容都在document里面

10、操作H5的自定义属性		 
	案例：\javascript_projects\javascript_exam_project\08-WEB_API_DOM\08-操作H5的自定义属性.html
	
	很多情况下元素自带的属性比如 class,id,name等，这些属性也叫标准属性，但是实际开发中标砖属性往往不够使用。
	在H5中推出来了专门的data-自定义属性
	在标签上一律以‘data-’开头，在DOM对象上一律以dataset对象方式获取
	比如：	
		<div class='box' data-id="100">盒子</div>
		<javascript>
			const box = document.querySelector('.box')
			console.log(box.dataset.id)
		</javascript>
		这里通过box.dataset.id 去访问对象的自定义属性 data-id的值
	
	注意:在标签上的自定义属性，如果使用了大写字母，在js中要用小写来访问
	比如：
		<div class='box' data-ID="100">盒子</div>
		<javascript>
			const box = document.querySelector('.box')
			console.log(box.dataset.id)
		</javascript>
	因此推荐不要在自定属性上使用大写字母，避免歧义，多个字母可以使用“_”来链接
	
11、事件监听
	案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\01-事件监听.html
	
	事件是在编程时系统内发生的动作或者发生的事情，比如用户在页面上单击了一个按钮，网络返回了数据等
	事件监听：
		就是让程序检测是否有事件产生，一旦事件触发，就立即调用一个函数做出响应，也称为绑定事件或者注册事件
		比如鼠标经过显示下拉菜单，点击可以轮播图等等
		
	语法：
		元素对象.addEventListener('事件类型'，要执行的函数)
	事件监听的三要素
		1）事件源：哪个DOM元素被事件触发了，要获取DOM元素
		2）事件类型：用什么方式触发，比如鼠标单击‘click’,鼠标经过‘mouseover’等
		3）事件调用的函数：要做什么事，该函数只有当事件触发的时候才会被调用
	
	比如：
		<button>按钮</button>
		<div class="box">点击关闭当前div</div>
		<script>
			const btn = document.querySelector('button')
			btn.addEventListener('click', function () {
				console.log("1) click事件触发");
			})
			
		    const div = document.querySelector('.box')
			function divfun() {
				console.log("div点击事件触发");
				div.style.display = 'none'
			}
			div.addEventListener('click', divfun)	//注意这里不能加括号，这里是函数引用，如果加括号，该函数会立即执行了		
		</script>
	
	事件监听的版本
		1）DOM L0:事件源.on事件=function(){}
		2）DOM L2:事件源.addEventListener('事件名',事件处理函数)
		3）DOM L3:DOM L3级事件模块的DOM L2的基础上重新定义了这些事件，也添加了一些新事件类型
		区别：on方式会被覆盖，addEventListener方式可以绑定多次，拥有事件更多特性，推荐使用L2的方式

12、事件类型

	鼠标事件，由鼠标触发的事件

		2）keyup,键盘抬起触发
	文本事件，表单输入触发

	事件触发：

		比如:click事件，当注册了事件函数以后，使用 元素.click() 的方式也可以让被注册的函数执行
			focus事件，同上

13、事件对象
	案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\03-事件对象.html
	
	事件对象：
		1）事件对象中含有事件触发时的相关信息
		2）例如：鼠标点击事件中，事件对象就保存了鼠标点击在哪个位置的信息
	
	使用场景：
		1）可以判断用户按下了哪个按键，比如按下回车键可以发布新闻
		2）可以判断鼠标点击了哪个元素，从而做出相应的操作
	
	语法：

		2）一般命名为event,ev,e

		2）clientx/clienty :获取光标相对于浏览器可见窗口左上角的位置
		3）offsetX/offsetY :获取光标相对于当前DOM元素左上角的位置
		4）key:用户按下的键盘按键的值，早期是keyCode,目前已经不提倡使用了
		
		
14、事件流
	
	事件流指的是事件完整执行过程中的流动路径
	
	假设页面里有个div元素，当触发事件时，它会经历两个阶段
	1）捕获阶段
		从Document对象到具体的元素的过程，比如某个div
		Document -> Element html -> Element body -> Element div
	2）冒泡阶段
		从具体的元素（比如某个div）到Document的过程
		Element div -> Element body -> Element html -> Document
	简单来说捕获阶段是从父DOM到子DOM的过程，冒泡阶段是从子DOM到父DOM的过程
	实际工作都是使用事件冒泡为主
	
	事件捕获：
		案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\04-事件捕获过程案例.html
		从DOM的根元素开始去执行对应的事件（从外到里）
		事件的捕获方式：
			元素.addEventListener('事件类型'，事件处理函数，是否使用捕获机制)
			是否使用捕获机制:true,代表是捕获阶段触发（很少使用），不填，默认为false代表是冒泡阶段触发
		比如：
		<style>
			.father {
			width: 100px;
			height: 100px;
			background-color: #09ebbe;
			}
		
			.son {
			width: 50px;
			height: 50px;
			background-color: #ebc509;
			}
		</style>		
		
		<div class="father">
			<div class="son"></div>
		</div>
		<script>
			const fa = document.querySelector(".father")
			const son = document.querySelector(".son")
		
			document.addEventListener('click', function () {
			console.dir(this)
			},true)
		
			fa.addEventListener('click', function () {
			console.dir(this)
			},true)
		
			son.addEventListener('click', function () {
			console.dir(this)
			},true)
		</script>
		该页面有一个father div，在father div内部还有一个son div,
		分别给document,father div 和 son div都注册了click事件
		如果不捕获，点击son div的时候先触发son div的事件，再触发father div的事件，最后触发document的点击事件
		如果捕获，则先触发document的点击事件，再触发 father div的点击事件最后触发son div的点击事件
		注意 ：DOM L0的事件监听（元素.onxxx()）,只有冒泡阶段，不支持捕获阶段
		
	事件冒泡：
		案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\05-事件冒泡过程案例.html
		当一个元素的事件被触发时，同样的事件将会在该元素的祖先元素中依次被触发（从里到外，父亲->爷爷->...->根），这一个过程被称为事件冒泡
		addEventListener的第三个参数不填写或者填写为false，则按照冒泡的方式执行事件流
		简单来讲，当一个元素触发事件后，会依次向上调用所有父亲元素的同名事件
		默认情况下冒泡一定会发生，没有效果是因为祖先元素没有注册同名事件，所以没有效果
		
	冒泡的阻止
		案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\06-事件冒泡的阻止.html
		
		因为默认冒泡模式的存在，所以容易导致子元素的事件会触发到父元素的同名事件
		如果想把事件限制在当前元素内，就需要阻止事件的冒泡
		要想阻止事件冒泡，需要拿到事件对象
		语法：事件对象.stopPropagation(),该函数即能阻止事件的冒泡，也能阻止事件的捕获
		比如：
		    son.addEventListener('click', function (e) {
				console.dir(this)
				e.stopPropagation()
			})
			该方法调用后，其祖先元素即使注册了click事件，也不会被执行了
	
	事件的解绑：
		案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\07-事件的解绑.html
		传统的方式（L0）是使用元素的onxxx()事件来注册的，要想解绑只要赋值为null即可
		比如：
			btn.onclick=function(){
				alert("hello")
			}
			btn.onclick = null
			
		目前推荐使用L2的方式：
			元素.removeEventListener('事件名',函数名[,获取捕获或者冒泡阶段])
			因为需要指定回调函数，因此匿名函数是无法被解绑的
		比如：
		    function btnClick(e) {
				alert("点击后解绑事件")
				btn.removeEventListener('click', btnClick)
			}
			btn.addEventListener('click', btnClick)

15、鼠标经过事件
	鼠标经过事件有两大类
	1）mouseover和mouseout，这两个事件会有冒泡效果
	2）mouseenter和mouseleave，这两个没有冒泡效果，因此推荐使用
	
	比如一个父div里有多个子div，使用mouseover和mouseout注册事件，当鼠标滑动到子div上的时候，冒泡机制会触发父div的离开事件
	此时父亲鼠标经过事件会被多次调用，会影响效率
	因此使用mouseenter和mouseleave去监听事件，比较好，他们阻止了事件的冒泡传递，不会多次让父元素的事件被调用

16、事件委托
	案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\08-事件委托.html
	
	事件委托是利用事件流的特征解决一些开发需求的知识技巧
	比如：
		<ul>
			<li>...</li>
			<li>...</li>
			<li>...</li>
			<li>...</li>
			<li>...</li>
		</ul>
		假设需求是每个li被点击的时候触发一些任务，传统的方式是利用选择器查找出来所有的li元素，循环给每个li元素注册点击事件
		事件委托的做法是仅在父元素，也就是ul上注册一次点击事件，当li被点击时，会自动冒泡到ul上，再由ul的事件统一处理
		
	优点：
		1）减少注册次数，可以提高程序性能
		2）原理：事件委托其实是利用事件冒泡的特点
		       给父元素注册事件，当子元素触发时会冒泡到父元素上，从而触发父亲元素事件
		3）实现：	通过事件对象.target可以获取真正触发事件的元素   
				通过事件对象.target.tagName，可以判断当前元素的标签名

18、页面加载事件
	案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\10-页面的加载事件.html
	
	加载外部资源（如图片，外联css，js文件等等）加载完毕时触发的事件
	
	默认情况下，js一般放到页面<body>标签的下方，这样页面从上到下加载完后，此时DOM元素已经初始化成功，后面的js才能正常执行
	更好的方式是，监听页面加载事件，等页面加载好以后再执行js，这样js就不需要必须放到页面的下方了
	
	事件名：load
	作用：监听页面所有资源加载完毕后回调
	通常load事件注册到window对象上，window对象是比document还要上层的页面对象，它代表整个浏览器窗口的声明周期对象
	
	load事件不光可以监听整个页面资源加载完毕，也可以针对某个资源绑定load事件
	比如：img.addEventListener('load',function(){...})//这里是等待img资源加载完成后再回调

19、DOM初始化成功事件
	事件名：DOMContentLoaded
	load事件是要等待所有资源加载完成之后才回调，而DOMContentLoaded事件是只要HTML的DOM元素初始化成功后就会回调
	它不需要等待样式、图片等外联资源加载完成后才回调，因此比load更先调用。
	某些情况下页面资源比较多，但是不影响当前页面js的执行，可以使用这个事件，提高页面响应效率
	
	使用方式:
		通常是给document添加DOMContentLoaded事件
		比如：document.addEventListener('DOMContentLoaded',function(){...})

20、元素滚动事件
	滚动条在滚动的时候触发的事件
	很多页面需要检测用户把页面滚动到某个区域后做一些处理，比如固定导航栏，比如返回顶部等等
	
	事件名：scroll
	案例：\javascript_projects\javascript_exam_project\09-WEB_API_事件\11-监听整个页面的滚动事件.html
	作用：监听整个页面的滚动
		window.addEventListener('scroll',function(e){})
		该监听，每次滚动都会回调
		给window或者document监听，整个页面滚动都会回调

30、js的执行机制

	浏览器通常要有两个引擎，一个用于渲染页面内容，另一个就是执行js的引擎，比如google浏览器的集成V8引擎
	
	js语言的最大特点就是单线程，也就是说，同一时间只能做一件事
	单线程就意味着，所有任务需要排队，前一个任务结束，才会执行后一个任务。
	这样导致的问题是：如果js执行的时间过长，就会照成页面的渲染不连贯，导致页面卡顿的感觉
	
	为了解决这个问题，利用多核CPU的计算能力，HTML5提出了Web Worker标准，允许js脚本创建多个线程。
	于是js中出现了同步和异步
	尽管 js 从 2012 年起具备了多线程能力，但其支持程度和易用性仍受限于浏览器环境和语言设计。
	也就是说js本是是不支持多线程的，为了提升js的异步能力，js把异步能力交给了浏览器去做
	
	同步任务
		同步任务都是在主线程中执行，形成一个任务栈
		
	异步任务
		js的异步是通过回调函数实现的
		通常来讲异步任务有三种类型
		1）普通时间，比如click,resize等
		2）资源加载，比如load,error等
		3）定时器，包括setTimeout,setInterval等
		异步任务相关添加到任务队列（也叫消息队列）中
		
	js的执行步骤
		1）先去顺序执行“执行栈”的同步任务
		2）遇到异步任务，会把异步任务提交给对应的异步进程处理。异步进程处理好任务以后，再把任务放到“任务队列”中去
		3）一旦执行栈中的所有同步任务执行完毕，系统就会按次序读取“任务队列”中的异步任务，
		  于是被读取的异步任务结束的等待状态，进入执行栈，开始执行
	由于主线程不断的重复获得任务，执行任务，在获取任务，再执行，所以这种机制被称为事件循环(event loop)
	
	常见的异步API
		1)ajax
		2)DOM事件
		3)定时器模块

34、本地存储
	案例：\javascript_projects\javascript_exam_project\11-WEB_API_BOM\04-localStorage的使用.html
	H5提出的网页应用数据保存方案
	1）数据存储在浏览器中
	2）设置，读取方便，甚至页面刷新也不会丢失数据
	3）容量较大，sessionStorage和localStroage约5M左右
	
	localStroage
	作用：可以将数据永久的保存带用户电脑中，除非手动删除，否则关闭页面也会存在
	特性：
		可以多窗口(页面)共享，同一浏览器可以共享
		以键值对的形式存储使用
	语法：
		1）储存数据：localStorage.setItem(key,value)
		   
		2）读取数据
			localStroage.getItem(key)
		3)删除数据
			localStorage.removeItem(key)
		4)注意：
			保存后，在浏览器的开发者工具->应用/Application -> 存储/Storage -> 本地存储空间/Local Storage
			可以看到当前域名页面的所有数据，跨域不会共享数据
			
			读取数据是以字符串类型返回的，即使保存的时候是数字、布尔类型、null等
			如果保存的是null,读取的时候是null这个字符串
			如果保存的是对象，保存的实际上是‘[object Object]’这样的字符串，并不是真实的数据
			
	sessionStorage
	生命周期为关闭浏览器窗口
	在同一个窗口(页面)下数据可以共享
	以键值对的形式存储使用，语法根localStorage相同
		
	读写复杂数据
		1）本地只能存储字符串，无法直接存贮复杂数据
		   语法：let jsonStr = JSON.stringify(复杂数据类型)
		   先将复杂数据的对象保存为一个json的字符串，再把json字符串保存到localstorage中去

		2）读取的时候由于是字符串，因此需要使用 let obj = JSON.parse(json字符串)，将字符串转换为对象
